# Behavior Package

Trigger workflows for ADHD cognitive load management, task initiation, and behavioral psychology principles.

## Triggers Overview

### ADHD & Cognitive Load Management

| Trigger | Label | Description |
|---|---|---|
| `:pshatter` | `[Behavior] Task Shatter (Overcome ADHD Inertia)` | Interactive form breaking daunting tasks into sub-minute micro-steps. |
| `:pmenu` | `[Behavior] Dopamine Menu (ADHD Stimulation)` | Generates a structured menu (Appetizers, Entrees, Sides) for stimulation. |
| `:pdouble` | `[Behavior] Virtual Body Doubling (30m Focus)` | Sets up a 30-minute accountability body-double check-in routine. |
| `:pswitch` | `[Behavior] Task Switch & Context Reset` | 3-minute mental palace cleanser routine to switch between cognitive contexts. |
| `:pgamify` | `[Behavior] Gamify Boring Admin Tasks` | Turns tedious tasks into a rewarding quest tied to personal interests. |
| `:paudit` | `[Behavior] ADHD Time-Blindness Reality Audit` | Reality-checks task estimates vs historical reality to unmask hidden sub-tasks. |
| `:ploops` | `[Behavior] My Brain Is Full Of 'Open Loops'` | Interactive multiline dump sorting items into Now, Later, and Trash with next steps. |

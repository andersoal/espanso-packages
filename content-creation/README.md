# Content Creation Package

A comprehensive collection of Espanso triggers and interactive forms for content strategists, writers, marketers, and creators.

## Included Toolkits

### 1. Writing & Voice Refinement (by @umohai)

A curated 10-prompt set for removing AI tone, stress-testing arguments, enforcing direct prose, and sharpening drafts.

| Primary Trigger | Aliases | Label | Function |
|---|---|---|---|
| `:kill-ai-voice` | `:ai-voice-kill`, `:humanize-voice` | Kill The AI Voice | Rewrite text matching your sample's rhythm, cadence, and vocabulary |
| `:cliche-pass` | `:strip-cliches`, `:anti-cliche` | The Cliche Pass | Replace generic clichés with context-specific phrasing |
| `:argue-back` | `:make-it-argue`, `:devils-advocate-draft` | Make It Argue Back | Generate the strongest counter-argument to test draft resilience |
| `:force-specifics` | `:concrete-examples`, `:no-generalities` | Force Specifics | Replace vague claims with concrete figures, names, and examples |
| `:strip-hedging` | `:remove-hedging`, `:direct-voice` | Strip The Hedging | Strip softeners and weak modal verbs for direct assertions |
| `:steal-structure` | `:copy-skeleton`, `:outline-mimic` | Steal A Structure | Reverse-engineer an outline skeleton and apply it to a new topic |
| `:five-whys` | `:5-whys-writing`, `:drill-down-why` | Five Whys | 5-step iterative probing to find the true thesis/core point |
| `:write-bad-version` | `:bad-version-first`, `:boring-draft` | Write The Bad Version | Draft the boring version first, analyze weaknesses, then fix |
| `:sceptical-reader` | `:skeptical-reader`, `:dropoff-audit` | The Sceptical Reader | Identify where and why a skeptical reader would stop reading |
| `:voice-lock` | `:lock-voice`, `:tone-enforce` | Voice Lock | Enforce a one-line restatement check for continuous tone guardrails |

# Career & Professional Trajectory Package

A modular collection of **Espanso** triggers and interactive AI prompt templates designed for senior engineering positioning, resume engineering, ATS optimization, and executive interview preparation.

---

## 🎯 Recruiter & Resume Review Series

| Trigger | Name | Description |
|---|---|---|
| `:res-attention` | **The Recruiter Attention Test** | Evaluates 10-second first impressions, visual scan hierarchy, and initial credibility. |
| `:res-mindset` | **The Recruiter Mindset** | Assesses resume competitiveness against hundreds of candidates for senior roles. |
| `:res-ats` | **The ATS Visibility Engine** | Extracts missing technical keywords from target JDs and naturally integrates competencies. |
| `:res-impact` | **The Impact Statement Rebuilder** | Converts passive task descriptions into metric-driven, quantified business achievements. |
| `:res-market` | **The Market Positioning Rewrite** | Aligns tone, summary, and skills with the communication culture of top-tier firms. |
| `:res-executive` | **Executive Resume Refinement** | Final-pass deep audit eliminating corporate fluff and maximizing executive authority. |
